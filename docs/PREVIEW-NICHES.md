# Preview niche blocks

A niche block is added to the end of the API instructions when a niche is chosen
(`--niche engineering`, or the "niche" box in the Build preview Action). Every hard rule in the
base instructions still applies. A move is used only if the site gives the facts for it.

## Engineering, fabrication and manufacturing
- Get a quote button in the header and after each section (the page adds these)
- Phone and email bar at the top (the page adds this, only if found)
- Hero line about what they make and who it is for (only what the site says)
- Service cards with one line each (from the site)
- Closing ask block (the page adds this)
- No customer names or logos of third parties on cold previews
