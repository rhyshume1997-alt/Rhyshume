# Project reference additions

The shared reference library is the single source: `.claude/skills/website-design-system/references/reference-library.md` (guides and research records sit beside it). This file holds **only what is specific to this repository**. Nothing here duplicates the library.

## Access notes for this repository's research environment

- Eleven reference hosts were blocked by the session network policy until the owner approved adding them to the environment allowlist on 2026-11-20 (rive.app, 21st.dev, www.motionsites.ai, www.scrolltide.co, landdding.com, land-book.com, sceneai.art, 60fps.design, scrollshaders.com, www.footer.design, styles.refero.design). The hosts remain allowed until the owner asks for their removal.
- Third-party images and video were not reachable, so media-driven effects could not be judged.
- Browsers: only Chromium is available in the cloud environment. WebKit (Safari's engine) could not be installed because its download host is blocked, so Safari was not tested.
