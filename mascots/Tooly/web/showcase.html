Tooly

A spanner you can talk to. Tooly is the face of Tolra's AI helper: ask in plain words, and the job gets sorted.

Press a move to see it. Tap Tooly for a squish.

Tooly inside an app

32 seconds: an iPhone app, a Mac app, then every move. The words are written for Tolra's helper.

Character sheet

Where each move goes in the helper

MoveWhen the helper
helloopens for the first time, or someone returns to it
thinkis working on an answer or an action
celebratefinishes something real, such as a quote drafted or a job despatched
oopsfails or hits the spend cap, with Try again beside it
sleepis switched off for the company, or has nothing to show yet
pointsuggests something to ask, one tip at a time
loveasks whether the answer helped

Using the web version

<script type="module" src="/mascot.js"></script>
<mascot-view src="/tooly" state="idle" style="width:200px"></mascot-view>

<script type="module">
  const m = document.querySelector("mascot-view");
  m.play("think");
  try { await ask(); m.play("celebrate"); } catch { m.play("oops"); }
</script>
