# Rhys Hume

Static site for Rhys Hume, Glasgow, hosted on Vercel at https://www.rhyshume.co.uk. HTML and CSS, no framework, one small inline script for the mobile menu button.

Pages: `index.html`, `websites.html`, `automation.html`, `tolra.html`, `csv.html`, `about.html`, `contact.html`, `privacy.html`, `404.html`, `work/jnr-engineering.html`, `council-digital-grants/index.html`. Shared styles are in `styles.css`. `vercel.json` turns on clean URLs, so `/websites` serves `websites.html`.

SEO files: `sitemap.xml`, `robots.txt`, `llms.txt`.
