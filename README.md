# Rhys Hume

Small static site for Rhys Hume, Glasgow. HTML and CSS only, no framework, no JavaScript.

Pages: `index.html`, `websites.html`, `automation.html`, `tolra.html`, `csv.html`, `about.html`, `contact.html`. Shared styles are in `styles.css`. Open `index.html` in a browser to view it.
