# Images

Each `placeholder-*.svg` file is a marked slot. To use a real image:

1. Save your photo or screenshot in this folder (for example `rhys.jpg`).
2. In the page named below, change the `src="images/placeholder-....svg"` to your file name and update the `alt` text.
