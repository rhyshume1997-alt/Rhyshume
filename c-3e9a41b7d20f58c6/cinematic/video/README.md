# Footage folder

Put the finished clips here, named after their key in `../data/footage.json` with `.webm` and `.mp4` extensions
(for example `se-hero-fire-4x5.webm` and `se-hero-fire-4x5.mp4`), then set `"available": true` for that key.
Nothing else changes. Specifications: `docs/concepts/asset-manifest.md`.

No clip is in this folder yet. The pages show their poster photographs until a clip is added.
